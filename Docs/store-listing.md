## Short description

A fast, private developer toolbox for Windows — format JSON, SQL and XML, diff text and JSON, test regex, encode Base64 and URLs, generate UUIDs and QR codes, convert timestamps, and build HTTP API requests. Fully offline.

## Long description

ForgeKitRk puts the small jobs you do every day into one quick, native Windows app — no browser tabs, no sign-in, no telemetry. Paste or drop a file and it just works, with a clean light/dark UI, a command palette, and keyboard shortcuts throughout.

Twenty tools in one place: JSON, SQL and XML formatters; JSON diff, text compare and a regex validator; JSON-to-C#, JSON-to-table and date and Unix-timestamp converters; Base64 text and image, URL and HTML encoders; UUID and QR code generators; a character counter, a live Markdown preview and an HTML viewer; SVG to XAML; and an HTTP API builder. Copy something to the clipboard and ForgeKitRk suggests the tool for it.

Everything runs on your machine. Every tool except the API Builder works with no network access at all; the API Builder sends only the requests you compose, and secrets stay in the Windows credential vault — never written to a file.

## Feature points

- Format, validate, and minify JSON, with JSONPath queries and large-file handling
- Semantic, structure-aware JSON diff with an exportable RFC 6902 patch
- Generate clean, compilable C# models from a JSON sample, or lay JSON out as a table for Excel
- Format SQL in ten dialects, and indent or minify XML
- Convert Unix timestamps and dates across time zones, from seconds to nanoseconds
- Encode and decode Base64 text and images, URLs and HTML entities
- Generate UUIDs (v1, v4, v7) in bulk and QR codes as PNG or SVG
- Compare texts side by side or inline and export the diff as HTML, and test regular expressions with groups and replacements
- Count characters, preview Markdown, and view HTML pages as you edit them
- Convert SVG shapes, paths, and gradients to WPF / WinUI XAML
- Build and send HTTP requests — methods, headers, auth, environments, cURL import/export
- 100% local: no telemetry, no analytics, no account, works offline
- Secrets held in the Windows credential vault, not in plain config
- Recent tools, favourites, and clipboard Smart Detect one click away
- Light, dark, and system themes with a fast command palette
